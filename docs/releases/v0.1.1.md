A maintenance release with one connection fix.

## Fixed

- **Fewer needless reconnects.** If AscendCord was busy at the moment its heartbeat to
  Discord came due, it could decide the connection had gone quiet even though Discord's
  reply was already waiting, then drop and rebuild the connection. It now reads anything
  that has already arrived before making that call. A server-side sign-out (session
  expired) is also reported as such instead of turning into a reconnect loop.
- **Source downloads use Linux line endings.** The source archive for 0.1.0 had Windows
  line endings in many files; 0.1.1 is clean, so scripts and the PKGBUILD work as-is.
