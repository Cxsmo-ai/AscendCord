Camera quality and screen sharing fixes.

## Fixed

- **Camera resolution selection uses the best available mode.** DirectShow now prefers
  the mode with the most source pixels when no mode reaches the selected size, instead
  of choosing a much smaller mode only because its aspect ratio matches. Camera video
  also recovers cleanly after dropped frames by requesting a fresh keyframe.
- **Screen shares stay up while a source is idle.** A minimized window or temporarily
  empty source no longer ends the share, and the UI keeps the reason when a share stops.
- **Inline video links work with current signed URLs.** AscendCord now accepts Discord's
  newer link-signing parameters while still refusing signed-link transformations. When
  a link cannot be embedded, the media proxy link remains available as a fallback.
