# v0.1.13

Improve sender-side music audio fidelity and rate controls.

## Improved

- Bundle Xiph libopus 1.6.1 for deterministic encoder builds.
- Preserve in-range capture samples and apply stateful Opus soft clipping only when samples exceed full scale.
- Keep 510 kb/s constant bitrate as the default; add selectable constrained and unconstrained VBR choices for comparison.

AscendCord continues to send ordinary stereo Opus packets that standard Discord clients can receive. No listener-side AscendCord feature is required.
