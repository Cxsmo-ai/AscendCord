Opt-in synthetic audio sweep testing with an automatically matched browser receiver capture.

## Audio test workflow

- Enable the synthetic stepped sweep and exact-channel auto-join only with
  `--test-sweep-channel=<voice-channel-id>`. Launching AscendCord without this argument keeps the
  normal microphone, call, and processing behavior.
- Package the Stereo Proof extension in the release so Edge and Chrome users can load it unpacked.
- Document installation, sender launch, automatic receiver capture, JSON export and measured PNG
  graph in [Stereo Proof audio testing](../stereo-proof-testing.md).
- Collect two matched sweep passes and the receiver's numeric loss, jitter, concealment, codec and
  decoded-spectrum metrics automatically. Reports contain no captured audio.
- Leave the test call after the receiver has saved its completed report; an explicit local stop also
  stays stopped for the rest of that launch.

## Downloads

The release workflow builds and verifies the Windows installer and portable ZIP, Arch Linux package,
PKGBUILD, Stereo Proof extension ZIP, and SHA-256 checksums from this tag.
