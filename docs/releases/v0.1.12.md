This release smooths capture-clock drift before it can turn into periodic whole-frame drops or repeats.

- Capture callback audio is paced to Discord's 20 ms packet clock with fractional polyphase resampling and a bounded, slowly adjusted buffer-fill matcher.
- Capture gaps advance the RTP media timestamp on the 48 kHz clock so the next packet retains the correct sampling time.
- The fixed 510 kb/s Audio/Music Opus path is tested for CELT-only mode, full-band frequency response, stereo separation, and packet size.
- Input processing remains disabled by default. Opus is still lossy, and capture-clock correction cannot eliminate packet loss or concealment on the network or remote client.
- Voice documentation cites the ASRC, RTP timestamp, Opus mode, and adaptive playout research and explains which measurements are local versus receiver-side.

The release workflow builds the Windows installer and portable archive, Arch Linux package, Stereo Proof extension archive, and SHA-256 checksums.
